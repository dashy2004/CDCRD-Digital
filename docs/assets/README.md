# Banner de CDCRD-Digital

El banner reproduce la versión actual aprobada y publicada por el responsable del
repositorio el 2026-10-17. Diseño editable: [Canva](https://www.canva.com/design/DAHYTip4pJ8/Cw9S-5IRfy_MZrj0EXIeaA/edit).

El lienzo original mide 1280 × 400 px. El PNG disponible mediante el conector de
Canva mide 800 × 250 px y mantiene la misma proporción; se conserva sin reescalado.
Para reemplazarlo por la exportación original, descargar PNG a 1× desde Canva y
actualizar `banner-cdcrd-digital.png`.

Las marcas de las aplicaciones identifican integraciones; pertenecen a sus
respectivos titulares.
