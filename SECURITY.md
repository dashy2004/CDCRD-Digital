# Seguridad

Los conectores de escritorio pueden leer y modificar el modelo abierto. Revisa el código, los permisos y el documento activo antes de habilitar escrituras. Trabaja con copias y conserva los recibos.

## Comunicar un problema

Para fallos que puedan describirse sin información sensible, abre una incidencia con la versión, el módulo, los pasos mínimos y un ejemplo sintético. No adjuntes credenciales, modelos privados, rutas personales ni registros completos sin revisarlos.

Si el problema contiene datos sensibles, utiliza un canal privado acordado con los mantenedores antes de compartirlos. Este repositorio no publica un compromiso de tiempo de respuesta.

## Alcance de las verificaciones

Las comprobaciones de GitHub Actions validan contratos y regresiones offline. Las pruebas CAD y sus versiones están documentadas en cada módulo. Una rama o versión no documentada no debe suponerse probada en la aplicación.
